# 食品标签合规预审工具（开源演示版）

> 一个**单文件、离线可跑**的食品标签合规自查工具。依据 **GB 7718-2025 / GB 28050-2025 / GB 2760-2024**，帮食品厂在**开印之前**发现标签上的硬伤。

---

## 为什么做这个

2025 版 GB 7718 与 GB 28050 已发布，**2027-03-16 强制实施**。核心变化之一：

> 营养成分表由 **1+4** 扩为 **1+6**——新增「饱和脂肪」和「糖」两项强制标示。

我拿市售 30 余个预包装食品实测，**近一半的营养表还停在 1+4**。改一个标签文件，比印废一万个包装便宜得多。

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| 规则比对 | 按标准逐条检查标签字段，红（必须整改）/ 黄（建议优化）/ 绿（通过）三级 |
| 依据可查 | 每条问题标注标准条款号（如 GB 28050-2025 第 4.1、4.5 条） |
| 改法可抄 | 每条给出可直接照抄的整改文字 |
| 报告导出 | 生成 PDF/打印版报告，含一页总览、问题明细、照片清单 |
| 完全离线 | 单个 HTML 文件，双击即用，数据不出本机 |

---

## 快速开始

```bash
git clone https://github.com/<your-name>/label-audit.git
cd label-audit
```

双击 `src/label-audit-demo.html` 即可运行（建议用 Edge/Chrome 打开）。

- 点击「载入并预审」用内置样例看效果
- 或在表单里填入自己产品的标签信息

无需安装任何依赖，无需联网。

| | 演示版（本仓库） | 商业版 |

## 技术栈

- 纯前端单文件（HTML + 原生 JS），零依赖、零构建
- 规则以 JSON 内联，便于审计与版本管理
- PDF 导出走浏览器打印（`window.print()`）
